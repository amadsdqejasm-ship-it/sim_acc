Telegram Account & Login Assistant
ئەم پڕۆژەیە پایتۆن (Python) بەکاردەهێنێت بۆ پێشکەشکردنی یارمەتییەک لەسەر ڕووکاری גרافیکی (GUI) بە شێوەیەکی یاسایی، ئارام و فەرمی بۆ پەیوەندیکردن بە پلاتفۆرمی Telegram لە ڕێگەی ⁠Telethon⁠ API فەرمی.
تایبەتمەندییەکان
￼ فەرمی و بێ بەزاندنی پاراستن: هیچ شێوازێکی ساختە (Fake numbers, bypass, anti-bot bypass) تێدا نییە و تەنها API فەرمی بەکاردەهێنێت.
￼ ڕووکاری گرافیکی ئاسان (GUI): بەهۆی ⁠Tkinter⁠ دروستکراوە کە پڕ بە دڵی بەکارهێنەرە.
￼ مامەڵەکردن لەگەڵ هەڵەکان (Error Handling): مامەڵەی ڕوون بۆ FloodWaitError، Invalid Code و Rate Limits دەکات بەبێ ئەوەی سیستەمەکە تێکبچێت.
￼ پاراستنی زانیارییەکان: هیچ credential یاخود پسوۆردێک هاردکۆد نەکراوە و لە لاگەکاندا پەنهانکراوە.
